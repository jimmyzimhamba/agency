Common questions

Do I need to install anything?

No app store required. Open it in your phone's browser and choose "Add to Home Screen." It behaves like a real installed app from there on.

What happens if my connection drops?

The app opens instantly from the last data it synced, clearly marked as "last synced," so you're never stuck staring at a loading screen. Live data resumes the moment you're back online.

Is there a cost?

Agency Command itself is free to run for your team. A couple of optional add-ons (like WhatsApp messaging through Twilio) have their own small usage-based costs from that provider, entirely separate from this app.

Can more than one person on my team use it?

Yes: create your agency's workspace once, then invite teammates with a simple invite code. Everyone sees the same pipeline, conversations and documents update live.
